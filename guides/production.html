生产部署 ​

将AI智能体系统部署到生产环境的完整指南。

部署准备 ​

环境配置 ​

bash
# 生产环境变量
export NODE_ENV=production
export API_KEY=your_production_key
export DATABASE_URL=your_production_db
export REDIS_URL=your_redis_url

依赖管理 ​

bash
# 安装生产依赖
pip install -r requirements-prod.txt

# 构建应用
npm run build
